# Feature maps

利用者の導線・実UI selector・検証上の注意を機能ごとに記録する。

- [CG-01 地図探索](map-exploration.md): パン・ズーム・選択と最小説明。
- [CG-02 詳細情報・関連・根拠](detail-evidence.md): 全選択対象の区分付き詳細・根拠・日付・欠損と条件同期。
- [CG-03 レイヤー独立切替](layer-toggles.md): 国境・主要航路・注目地点の独立表示、条件往復と非表示対象の選択保持。
- [CG-04 地図状態付き発見メモ](map-notes.md): 本文と完全な保存時条件のブラウザ内保存・一覧・削除・再読込保持。
- [CG-05 条件実験](scenario-switch.md): 通常時⇄通行不可（仮定）、候補・差分・同期とモデルの限界。

- [CG-06 メモからの地図状態復元](note-restore.md): 保存条件・選択・viewportの再訪と探索継続、新しいメモの保存。

機能の存在と受入の完了を区別する。自動操作・人間探索の結果は実走後の証拠へ残す。
