# CG-04 地図状態付き発見メモ

地点を選んだ説明欄の直下にある「この発見をメモする」（`#note-open`、aria-expanded）で入力欄（`#note-form`）を開き、ラベル「メモ本文」のtextareaへ入力して「メモを保存」を押す（UX-07）。入力欄には「保存する状態：条件 / レイヤー / 選択」を表示し、条件・レイヤー・選択が変わると追従する（表示範囲は保存されるが行には出さない）。「閉じる」で閉じても本文は欄に残り、開くボタンに「（下書きあり）」と出る。保存結果は入力欄の`#note-save-status`に出す。保存済み一覧はページ下部の「発見メモ」に残る。本文と保存日時（JST）、保存時の条件、国境・主要航路・注目地点それぞれの表示／非表示、選択地点を新しい順の一覧で読める。選択なしの記録は「選択なし」と表示する。現在の探索では初期選択のマラッカ海峡を含む既存の選択規則を維持する。

本文は入力した文字列のまま表示する。保存後に条件・レイヤー・選択・表示範囲を変更しても、一覧の保存内容は変わらない。一覧で本文と関連状態を常時読める。CG-06で追加した「このメモの地図状態に戻す」から再訪できる（[復元の詳細](note-restore.md)）。空白だけなら理由を示し保存しない。保存失敗時は本文を入力欄に残し、成功したメモとして一覧へ追加しない。

各件の「このメモを削除」は、アクセシブル名に本文と日時を含む。削除後は同じ位置の次の削除ボタン、末尾なら前の削除ボタン、空になったら入力欄へフォーカスを移す。削除・復元の結果は一覧側の`#notes-status`、保存の結果は入力欄側の`#note-save-status`のlive regionで知らせる。キーボード、狭い画面、モーション削減設定に対応する。

## 保存境界

`localStorage`の`chizu-no-gyokan.notes.v1`へ、`{version: 1, notes: [...]}`を保存する。各件は`{id, body, createdAt, mapState}`。mapStateは`scenarioId`、全レイヤーのbooleanを持つ`layers`、`selectedFeatureId`（なしなら明示的なnull）、中心の経度・緯度とzoomを持つ`viewport`からなる。viewportはCG-06で既存の表示範囲制約内に復元する。保存直前と読込時にunknownから検証し、必須状態の欠落を補完しない。

不正な記録や重複IDは正常な一覧から除外し、「読み込めない記録がN件あります」と表示する。正常なメモの保存・削除でも、除外した記録の元データは保持する。不正JSONや対応外のバージョンは書き換えず、読込・保存の失敗として案内する。保存領域のアクセス拒否・容量超過・書込例外も失敗として返す。

このブラウザ内だけに保存し、別端末へ自動同期せず、アカウント不要、外部へ送信しない。保存・削除を行わない探索ではstorageに書き込まない。入力欄の下書きはページ内だけに保持し、再読込では残らない（storageに書かないため）。メモ編集・共有・エクスポート・URL反映は含まない。復元と再訪後の探索継続は[CG-06](note-restore.md)に記録する。

## 検証

`npm run typecheck`、`npm test`、`npm run test:privacy`、`npm run test:geometry`、`npm run build`の後に`npm run verify`、`npm audit --json`。最新の実走結果はCIとPR本文を参照。

`tests/notes.test.ts`は両シナリオ×全レイヤー組合せ×選択あり／なし、完全状態の保存と読込、コピーと日時順、欠落・不正JSON・バージョン違いの拒否、破損記録の件数と保持、保存失敗、個別削除を検証する。

`tests/e2e/notes.spec.ts`はPC/mobileで次を確認する。

- 両シナリオと全レイヤー組合せを実UIで保存し、再読込後の条件・選択と照合する。
- 空状態、複数件の本文・JST日時・異なる条件／レイヤー／選択、地図変更後のスナップショットとviewport記録。
- 再読込で全保存内容を保持し、個別削除後の再読込では対象だけが消える。保存記録を読むことで現在の地図は変更しない。
- `Storage.prototype.setItem`の例外で保存失敗・本文保持・一覧不追加。削除失敗時の保持。保存領域を使えない場合の案内。不正記録の件数と「選択なし」。
- HTML文字列を保存して再読込し、dialogやonerrorの実行、img/scriptの生成がない。
- 保存・一覧・削除・再読込の全requestを記録。同一originの静的アセットと既存データのみで、本文・関連状態を要求URLや本文に含めない。
- Tab／Shift+Tab、Enter／Space、削除後フォーカス、live region、reduced motion、CG-06の復元ボタンのみを追加した一覧の操作順。

画像は`artifacts/map-exploration/notes-{desktop|mobile}-{empty|multiple|save-failure|html|keyboard}.png`へ保存する。coordinator runnerで実走し、画像を開いて文字と条件の対応、狭い画面、入力と削除の操作、フォーカスを確認する。[verify手順](../.cursor/skills/verify-chizu-no-gyokan/SKILL.md)を参照。

人間の自由探索と実際のスクリーンリーダー確認は未実施。自動操作で代用せず、保存内容と当時の条件が一覧から理解できるか観察して記録する。保存を探索の進行条件にせず、報酬・クイズ・正解判定を設けない。
