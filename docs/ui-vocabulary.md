# UI 用語集

画面上の語彙を統一するための一覧。同じ状態・操作には場所によらず同じ言葉を使う。状態（今どうなっているか）と操作（押すと何が起きるか）を混ぜない。対象は利用者に見える文字列・アクセシブル名で、コード内の識別子（`scenarioId` など）や開発者向け文書の略記は対象外。

## 状態を表す語

| 語 | 意味 | 使う場所 |
| --- | --- | --- |
| 現在の条件：通常時 ／ 現在の条件：通行不可（仮定） | いま地図が表す条件 | 地図内ラベル（読み上げ用に同じ文を条件ボタンの横にも持つ） |
| 表示中 ／ 非表示 | レイヤーの表示状態（`layerStateLabel`）。「ON/OFF」「表示/非表示」の揺れを使わない。差分要約の「表示／非表示」タグ（`changeLabels`）は別概念 | 表示レイヤーの読み上げ用 status、凡例の括弧、メモの「保存時の条件」欄、「〜レイヤーが非表示」の注記（`hiddenLayerReason`） |
| 選択なし | 対象が選ばれていない | 選択欄の見出し、メモの「選択地点」 |
| 事実 ／ 仮定 ／ モデル | 情報の区分タグ。正式名は「事実（地理的事実）」「仮定（シナリオ上の仮定）」「説明・推論（モデル上の説明）」 | 選択欄・詳細の各項目 |
| 仮定 ／ 変更 ／ 追加 ／ 表示 ／ 非表示 | 差分要約の各項目の種類 | 「何が変わった？」の要約 |
| 未収録 | この教材に根拠データを収録していない。ゼロや無影響ではない | 詳細「この教材では扱わないデータ」 |

## 操作を表す語

| 語 | 結果 | 使う場所 |
| --- | --- | --- |
| 通常時 ／ 通行不可（仮定） | その条件に切り替える（押下中の方が現在の条件） | 条件を選ぶボタン群 |
| なし ／ 日本 ／ シンガポール ／ 中国 ／ インドネシア | 国ごとの視点に切り替える（押下中が現在の視点）。「視点の焦点」は地図と一覧で強調される対象 | 視点ボタン群・一覧 |
| 通行不可にして変化を見る | 条件を仮定へ切り替え、差分を表示する | 初回案内の主ボタン |
| 国境 ／ 主要航路 ／ 注目地点 | そのレイヤーの表示を切り替える。ラベルは変えず、状態は aria-pressed が唯一の読み上げ経路。☑／☐は装飾（aria-hidden） | 表示レイヤーのトグル |
| タッチで地図を動かす | モバイルで地図ドラッグを有効／無効にするトグル（aria-pressed が状態）。地図右上に置き、直下の `#map-hint` に「指でなぞると何が起きるか」を表示 | 地図上（モバイル） |
| ＋ 拡大 ／ − 縮小 | 地図を1段階ズームする | 地図操作 |
| 対象地域に戻す | 初期の表示範囲（両候補海峡と航路全体）へ戻す | 地図操作 |
| 通れなくしてみる ／ 元に戻す | 地図上のマラッカ海峡で条件を仮定へ切り替える／通常時へ戻す（読み上げ名は「通れなくしてみる：マラッカ海峡（仮定）」「元に戻す：マラッカ海峡を通常時へ」） | 地図上の海峡の記号の下 |
| スンダ経由を試す ／ ロンボク経由を試す | その候補の線・名札・海峡を強調し、もう一方を控えめにする（aria-pressed が状態。もう一度押すと解除）。地図上で候補の線や海峡を選んでも同じ。船を迂回させた、とは言わない | 仮定時の地図操作 |
| 通常時に戻す | 条件を通常時へ戻す（候補の強調も解除） | 仮定時の地図操作 |
| 仮想船（教材モデル） ／ 仮想船：この先へ進めない（仮定） ／ 仮想船：〜経由を検討中（教材モデル） | 航路の起点に置く教材上の船の状態。実船・AISではなく、候補を選んでも動かさない | 地図上（主要航路レイヤー） |
| 〜を選択 | その対象を選び、説明を表示する | 一覧・地図上の対象（aria-label） |
| 閉じる ／ はじめ方を見る | 初回案内を閉じる／再表示する | 初回案内 |
| メニュー ／ メニューを閉じる | 設定と資料（視点・表示レイヤー・対象一覧・操作方法・読み方と注意・出典・保存済みメモ）を開く／閉じる。「メニュー」はラベルを変えず aria-expanded が状態 | ヘッダー、メニュー内 |
| 〈名称〉：なぜ重要？ | 選択中の対象の説明カードを開く／閉じる（aria-expanded が状態）。対象を選ぶと自動で開く | 地図の左（PC）／地図の下（スマートフォン） |
| 地理データを再読み込み | 読込失敗後に再取得する | 読込状態 |
| この発見をメモする ／ メモ欄を閉じる | 選択中の地点の横でメモ入力欄を開く／閉じる。閉じても本文は残り「（下書きあり）」と示す | 説明カードの中 |
| メモを保存 ／ このメモを削除 ／ このメモの地図状態に戻す | 発見メモの操作 | メモ入力欄・保存済み一覧 |

## 線種と記号

| 表現 | 意味 |
| --- | --- |
| 破線 ┄ | 通常主要航路（概略モデル） |
| 点線 ×┄ | 仮定時に使用しない比較線 |
| 長短破線 ＋┄ | 仮定時に追加する経由候補（概略モデル） |
| ◇ ／ ×◇ ／ ＋◇ | 海峡の代表点／通れない仮定／仮定時に追加 |
| ● | 関連地点の代表点 |

凡例・差分要約・選択欄・一覧・地図上のラベルは、同じ役割に同じ記号を使う（`featureSymbol`）。色だけで区別しない。
