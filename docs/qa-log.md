## 所見と対応

| # | 発見 | 再現手順 | 優先度 | 対応 |
| --- | --- | --- | --- | --- |
| 1 | 地図上の「マラッカ海峡」の名札が「スマトラ島」「インドネシア」の地名と重なり読めない | PC／phone で初期表示を開く | P1（記号と名前の対応が読めない） | 名札を記号の左上に移動（`.callout-malacca .feature-name`）。UX-10 の PR で修正 |
| 2 | phone で「はじめ方を見る」の高さが 32px（36px 未満） | 初回案内を閉じる → 表示されるテキストボタンを測る | P2 | `.text-button` の最小高さを 36px に。UX-10 の PR で修正 |
| 3 | phone の「タッチで地図を動かす」の案内が一度も表示されていなかった（CSS の `display: none` が後勝ち） | UX-08 の実装中に発見 | P1 | UX-08 の PR 内で修正済み（`hidden` 属性のみで制御） |
| 4 | 関連する場所のボタン名が一覧の「〜を選択」と衝突し、支援技術で同名の操作が 2 つになる | UX-06 の実装中に発見 | P1 | UX-06 の PR 内で修正済み（関連ボタンは可視名のみ） |
| 5 | 差分要約の live region が、内容が同じでも条件・レイヤーの再描画ごとに再通知される | UX-04 のレビューで発見 | P2 | UX-04 の PR 内で修正済み（同一内容なら再描画しない） |
| 6 | 視点パネルの「注目する対象」は条件によっては大半が非表示（通常時のインドネシア視点は 5 件中 4 件） | 通常時で「インドネシア」を選ぶ | P2（案内は出る） | 仕様どおり案内を表示。人間テストで迷いが出れば、視点選択時に仮定への切替を促す文言を検討 |
| 7 | phone の案内バナー（`#map-hint`）が国名ラベルに重なる | phone で初期表示 | P2 | 現状維持。表示は一時的でなく常時のため、人間テストで邪魔かを確認してから判断 |

対応するものは本 PR で修正し、残りは人間テストの結果とあわせて判断する。新規 Issue は人間テスト後に、再現手順つきで起票する。
